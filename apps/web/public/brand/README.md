# Bollywood Connect Premium Asset Kit

Included:
- Original high-resolution generated logos and brand mockups.
- 4K upscaled logo exports for splash screens, landing pages, and presentation use.
- App icon sizes: 1024, 512, 256, 192, 180, 128, 64, 48, and 32 px.
- Favicon `.ico` exports.
- Web navbar/footer PNG exports.
- Brand color tokens and CSS/font recommendations.

Important font note:
Font files are not included or redistributed. Use licensed fonts from Google Fonts, Adobe Fonts, or your own font library.

Recommended logo fonts:
- Cinzel / Cinzel Decorative for premium Bollywood-style gold title text.
- Orbitron or Syncopate for futuristic gaming style.
- Audiowide for high-tech arcade/game identity.

Recommended UI fonts:
- Inter, Montserrat, Poppins, or Rajdhani.
